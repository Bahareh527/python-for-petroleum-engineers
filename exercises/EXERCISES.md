# Exercises

1. Write a function that returns core bulk volume from diameter and length. Reject zero
   or negative dimensions.
2. Compare planned and completed well-name sets; report missing and unexpected wells.
3. Convert [1000, 1500, 2000] psi to MPa without an explicit Python loop.
4. Filter the synthetic well table to porosity above 0.20 and water saturation below 0.30.
5. Calculate OOIP for each well drainage area and summarize by field.
6. Recover permeability from a synthetic linear coreflood observation.
7. Plot IFT against pressure, using color for temperature.
8. Compare exponential and hyperbolic rate forecasts after 36 months.
9. Report OOIP P90, P50, and P10 from 20,000 reproducible simulations.
10. Create a one-page field-screening recommendation with assumptions and limitations.

Reference implementations are available in solutions/answer_key.py.
