# Teaching guide

Ask learners to predict outputs before executing cells. Require units in variable names,
tables, axes, and written answers. Use failed validation examples to discuss why
physically impossible inputs should be rejected early.

The synthetic datasets deliberately contain understandable trends and random variation.
Do not present those relationships as empirical correlations. Encourage learners to
replace them later with a licensed dataset and a documented data dictionary.

Solutions are provided in solutions/answer_key.py. Instructors may remove that directory
from a classroom fork before assigning exercises.
