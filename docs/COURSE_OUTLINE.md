# Course outline

## Audience and prerequisites

Undergraduate petroleum-engineering students and practicing engineers with algebra and
basic reservoir-engineering knowledge. No previous programming experience is required.

## Suggested delivery

Ten 90-minute sessions. Each session combines a short explanation, live coding, a
worked petroleum example, and one independent exercise. Module 0 can be assigned before
the first class; Module 9 is a two-hour capstone.

## Assessment

- Foundations and units: 20 percent
- Data analysis: 25 percent
- Engineering calculations: 30 percent
- Capstone communication and reproducibility: 25 percent

Grade reasoning, unit discipline, validation, and communication—not only final numbers.
