# Teaching data

All CSV files here are deterministic synthetic datasets generated by
petroleum_python.synthetic with seed 42. They contain no real fields, wells, companies,
students, or proprietary measurements.

- synthetic_wells.csv: static well and reservoir properties
- synthetic_ift.csv: illustrative pressure-temperature-salinity-IFT table
- synthetic_production.csv: noisy decline histories for three fictional wells

Regenerate them with python scripts/generate_data.py. The synthetic relationships are
educational constructs and must not be treated as physical correlations.
